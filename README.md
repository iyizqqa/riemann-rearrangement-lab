# Лаборатория перестановок Римана

Интерактивное русскоязычное веб-приложение для конструктивной иллюстрации теоремы Римана о перестановке членов условно сходящегося ряда.

## Математическая идея

Если ∑aₙ условно сходится, то положительные члены в сумме дают +∞, отрицательные — −∞. Для конечного L берём положительные члены до первого строгого пересечения L сверху, затем отрицательные до первого пересечения снизу и повторяем. Каждый исходный индекс используется не более одного раза, а оба потока исчерпываются по порядку. Перескок ограничен последним добавленным членом и стремится к нулю.

Ряды: периодический (1,1,−2)/n; (−1)ⁿ⁺¹/n; (−1)ⁿ⁺¹/√n; sin(n)/n. Первые три обосновываются Дирихле/Лейбницем и расходимостью соответствующих p-рядов; для sin(n)/n расходимость ряда модулей следует из положительного среднего |sin n| (равномерного распределения n по модулю 2π).

Для +∞ на этапе k положительными членами превышаем k, затем включаем один отрицательный член; для −∞ симметрично. Это гарантирует, что используются обе подпоследовательности и суммы уходят в нужную бесконечность.

## Технологии

HTML, CSS, ES Modules JavaScript, Plotly.js (через CDN). Нет backend, базы данных или обязательной сборки. Нужен интернет для графиков.

## Запуск на macOS

Из папки проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Тесты

При наличии Node.js 20+: `npm test` (npm install не требуется). Тесты не используют внешние пакеты.

## Публикация

Разместите все файлы в публичном GitHub-репозитории. Settings → Pages → Deploy from a branch → main → /(root). Сайт будет доступен по адресу `https://USERNAME.github.io/REPOSITORY/`. Необходимо подключение к интернету для Plotly.

## Интерфейс

Настройки ряда, L, ε, предела шагов и скорости; START/PAUSE/STEP/RESET; частичные суммы, числовая прямая с дугами, ошибка, перескоки, статистика, таблица последних шагов, эксперимент N(ε), раздел «О проекте», режимы ±∞.

## Ограничения

* Все расчёты конечны, JavaScript Number имеет ограниченную точность.
* Первое попадание в ε-окрестность **не означает** сходимости. «Наблюдаемый хвост» относится только к вычисленным членам.
* Большие цели L требуют чрезвычайно много членов; заданный лимит шагов может быть исчерпан.
* Графики прореживают данные при большом числе шагов, вычислительный алгоритм — нет.
* Анимация дуг показывает реальные точки на оси, но высота дуг выбрана условно.
* При MAX интерфейс обновляется пакетами, поэтому таблица показывает последние визуализированные шаги, а не каждый из них; математическое ядро выполняет все шаги.

## Структура

`js/core/` — математическая модель, потоки членов, алгоритм, статистика; `js/ui/` — графики и геометрическая иллюстрация; `js/app.js` — контроллер, ввод и DOM; `tests/` — тесты.

## Сценарий защиты (3–5 минут)

1. Объяснить условную сходимость и теорему Римана.
2. Выбрать периодический ряд, L = 1; выполнить три шага и показать первое пересечение сверху и снизу.
3. Запустить симуляцию с L = π и наблюдать пересечения и уменьшение перескоков.
4. Показать график ошибки, N(ε), сохранённые исходные индексы.
5. Открыть «О проекте», пояснить, почему эксперимент не заменяет доказательство.
